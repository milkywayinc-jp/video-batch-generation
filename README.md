# 動画一括生成

Googleスプレッドシートの台本と指定から動画を編集する、Codex用スキルとローカルCLIです。設定は毎回シートから読み、行別指定を優先します。

## はじめる

リポジトリ全体を取得し、Codexのプラグインまたはスキルとして導入してください。単体スキルの入口は `SKILL.md` です。参照資料とCLIも必要なので、フォルダ全体を保持します。

導入後、Codexへ：

> 動画一括生成をセットアップして、新しい制作チャットと自分用の台本シートのコピーを作って。

管理者から受け取った配布基準版へのアクセスが必要です。台本・書式込みで自分用にコピーし、制作チャットを準備します。チャット作成機能がない環境では、コピーURLと開始文を渡します。

配布の形は保存済みの **2026-10-20-v1** を維持します。制作時は各利用者が編集したコピーの最新内容を使います。

## 制作の流れ

1. 「このシートで生成して」と制作シートURLを渡す。
2. Codexが★付きタブの指定を読み、素材・音声・カットを準備する。
3. 生成音声を指定先に保存し、実測秒数とH列の合計を書き戻し、動画をプレビューで確認する。G列に合計ラベルは追加しない。
4. 承認後、指定先へ引き継ぐ。

必要環境はPython 3.9以上、ffmpeg / ffprobe、Pillow、認証済みgws CLI、指定フォント・素材・取得済み音声です。TTS自動生成APIと広告入稿はこのCLIに含みません。

ダウンロード・clone・閲覧だけでは、生成・チャット作成・Driveへの書込は動きません。台本・素材・認証情報は非公開で管理し、元シートや共有権限を変更しません。
