# 制作確認

具体的な秒数・速度・音量・座標は最新シートと利用者の指示から決める。以下は今回の制作で見つかった確認方法であり、特定案件の値を他の台本へ固定するものではない。

## カットとアップ

- 「一番動きがある部分」は、伝えたい動作の強さで選ぶ。素材全体を見て候補を比較し、採用区間と理由を記録する。画面差分の最大値は候補探しに使うだけ。台本の主動作を、準備動作や付随的な動きより優先する。
- 個別の開始・終了・継続・倍速を優先する。未指定行も確認し、一律の冒頭切出しで埋めない。続き指定は元素材の時間軸で接続する。
- 「アップ」は指定対象が明確に大きく見える構図にする。腹部だけ／顔と腹部など対象を読み、字幕・注釈と重ならないか確認する。動的ズームは採用する短い区間の中で変化するように作る。
- 倍速は映像と素材音声を連動させる。声の高さを保つ場合は`atempo`等を使い、区間を変換後の時間軸へ対応させる。発話の頭・末尾を欠かさない。現CLIに倍速を直接指定する項目はないため、必要な場合は映像と音声を同期変換した派生素材を先に用意し、出典・変換条件を私有記録に残す。
- 元素材のdurationだけで尺を保証しない。特に終端付近は、実際に符号化されたフレーム数と末尾の動作を確認する。足りなければ意図を保つ範囲で開始を戻すなどし、無断でループしない。

## 色

元素材と最終MP4の同じ場面を比較する。色褪せた場合は、まず`ffprobe`でprimaries / transfer / matrix / range、ビット深度、HDR・Dolby Vision情報、回転を調べる。

HLG/PQ/BT.2020素材を単に8bit化・BT.709タグ付けして済ませない。出力がSDRなら、素材に応じた線形化・色域変換・トーンマップ・BT.709出力を行い、その後に必要な見た目を調整する。HDRの褪色を強い彩度補正だけで隠さない。

ffmpegの`zscale`等の有無を確認し、不足なら変換可能な環境を用意する。共有のffmpegを無断で置き換えない。現CLIはHDRを自動でトーンマップしないため、必要な変換済み派生素材を先に用意する。変換済み中間素材だけでなく、結合後の最終動画の該当区間まで色とフレームの色特性を確認する。

## 音声と最新版

音量の数値に加え、ざらつき・歪み・不自然な抑揚を試聴する。強すぎるコンプレッサーやリミッターで目標だけを達成しない。元のfloat音声から調整し、同じ処理を重ねない。音量目標はシートから読み、変更が必要なら利用者の指示を得る。AAC後の音量とピークも確認する。

音声用テキスト・改行・間・速度・声の指定が変わったら、影響を確認して再生成の要否を判断する。利用者が「今回は再生成しない」と指定した場合はその範囲で尊重し、取得済み音声と現在の台本・行境界を照合する。空白除去後の一致だけで読み方・間も同じと決めつけない。新しいplanで準備し直し、旧receiptを使い回さない。ASRは発話位置の補助にとどめ、誤認識した単語で台本や字幕を書き換えない。

## 保存

生成音声動画も納品対象として、シートの命名規則と音声保存先へ保存する。最終動画の納品先とは区別する。指定外の「【見本】」等は付けない。利用者が除外を指定した接頭辞がシート名に含まれる場合も、保存名へ持ち込まない。必要なら書出し後に指定名へ変更し、最終名と同じ内容ハッシュを引継ぎ記録へ残す。採用バージョンとバッチ順を確認し、Drive上の名前・親フォルダ・容量・利用可能な内容ハッシュを照合して記録する。保存先が空なのにローカルのファイルパスだけを渡して完了にしない。

ローカル保存を避ける指示がある場合、必要な作業ファイルだけ一時使用し、保存と読戻し完了後に許可されたファイルを削除する。素材の一括先読みや旧版の蓄積を避ける。削除済みの私有記録にはDrive ID・ハッシュを残し、再編集時は必要なファイルだけ取得する。保存先の権限を広げない。

## 秒数と引継ぎ

- 書戻しと読戻しを済ませてから最終プレビューを表示する。H列に行別秒数と最終カット直後の合計を置く。G列に合計ラベルは追加しない。末尾無音は一度だけ含める。
- 「小数第2位まで切上げ」の指示なら、各行の実尺と全編の実尺をそれぞれ切り上げる。丸めた行秒数の和を合計にしない。表示は`0.00`、フレーム・サンプルの内部計算は丸めない。現CLIの標準writeback/receiptはフレーム由来の実秒数を照合し、切上げ指定には未対応。必要な場合はこの制約を伝え、切上げ値の書込とreceipt照合の両方に対応する実行方法を用意・検証してから進める。書込値だけの手動補正や表示書式の変更で標準CLIが対応した扱いにしない。
- ★対象一覧と最新版を再照合し、最終ファイル名・本数・順序・SHA256・検証・利用者の承認を結び付ける。旧版を渡さない。
- 今回だけのプレビュー指定や再生成しない指示を、全案件の固定ルールへ広げない。送信先・内容が既に承認されていれば同じ確認を繰り返さず、許可された範囲で引き継ぐ。送信完了と受領先の保存・入稿完了は分けて扱う。
